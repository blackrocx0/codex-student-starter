# Wiki Query

1. 先讀 `wiki/index.md`，只開啟與問題相關的 Wiki 頁面。
2. 預設以 `wiki/` 為回答來源；不要直接把 `raw/` 的未整理內容當成已驗證知識。
3. 回答中附上使用過的本地 Wiki 檔案連結。
4. Wiki 沒有答案時直接說明缺口：
   - 若 raw 有候選資料，建議執行 `wiki-ingest`。
   - 若本地完全沒有資料，詢問使用者是否要提供來源或允許外部研究。
5. 不因缺資料而補寫看似合理的事實。
6. 在 `wiki/log.md` 追加一筆簡短 `QUERY` 紀錄；不得寫入問題中的敏感個資。

輸出以直接回答為主，不需要先重述整個 Wiki 架構。
