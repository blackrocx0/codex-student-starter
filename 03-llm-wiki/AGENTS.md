# LLM-WIKI 模組規則

## 專案邊界

開始工作前確認目前資料夾名稱是 `03-llm-wiki`。若不是，停止並請使用者在 Codex 重新選擇此資料夾。不得讀取 `01-work-program` 或 `02-presentation-design` 兄弟資料夾。

## Source of truth

- `raw/` 是原始資料層：不可覆寫、摘要後刪除或「順手修正」。
- `wiki/` 是可維護知識層：允許整合、更新與互相連結。
- `config.yaml` 與 `templates/` 定義格式。

## 寫入規則

- 一個核心主題一個頁面，檔名使用 kebab-case。
- 頁面必須列出 repository 內相對來源路徑。
- 來源無法支持的推論標記為 `> ⚠️ 待確認：`。
- 不同來源衝突時並列差異與來源，不自行消除衝突。
- 更新頁面後同步更新 `wiki/index.md`。
- `wiki/log.md` 只能追加，不刪除舊紀錄。

## 隱私

- 不要把對話中的敏感個資寫進 log。
- 原始資料若含憑證、付款資料、身份證件或私人郵件，停止匯入並請使用者先移除／遮蔽。
- 外部研究需要使用者同意與可用網路工具；不得用模型記憶冒充已查證來源。
